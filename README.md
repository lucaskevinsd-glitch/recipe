# 健康菜谱与健身

手机版健康应用：健康菜谱大全 + 健身动作库 + 食材库，三个独立板块。

- **菜谱**：每道菜含名称、别名、功效作用、富含营养、对身体部位的好处、食材用量、做法步骤、配图；附每天吃什么（三餐灵感 / 一周搭配）
- **健身**：按胸、背、肩、手臂、腿分组，每个动作含目标肌肉、推荐组次、动作要点
- **食材库**：537 种单一食材（18 分类），别名搜索；选 1–6 种食材生成做法与步骤；点击食材查看图片与详情介绍

## 使用

直接用浏览器打开 `index.html` 即可（单文件应用，无需构建）。
