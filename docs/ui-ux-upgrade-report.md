## 2. 八个参考网站的研究结论

研究方式：官方页面文本读取 + Mobbin 浏览库真实浏览器复核（只读，未登录、未注册、未付费）。

| 网站 | 实际可访问情况 | 值得借鉴 | 不适合 / 未采用 |
|---|---|---|---|
| Scrolltide | 官网营销页可读：滚动驱动模板、GPU 动态背景、按乐段划分的页面节奏 | 首屏视觉焦点 + 按段落区分节奏（对应本次首屏图片化与分区差异化） | 全页滚动劫持、视差、WebGL 背景：会损害参考工具的查找效率与移动端性能，未采用 |
| Mobbin | 营销首页可读；`/browse` 文本抓取 403，真实浏览器复核确认：未登录访问被重定向回营销首页，无登录弹窗文案、无直接付费墙价格，但**真实可搜索的屏幕库未向匿名访客开放**；演示图中无 Food/Cooking/Recipe 分类 | 演示画面中的浏览模式：Apps/Sites 切换 + 居中搜索、Latest/Most popular 排序 + Filter、大截图卡片配图标与一句话简介（与本站搜索优先、卡片信息结构一致，予以确认而非照搬） | **未声称研究过真实美食类产品流程**：美食/烹饪/收藏/份量调整等流程因未登录不可见，本报告不以此为据 |
| Fontshare | 字体目录页可读：Satoshi、Clash Display、General Sans 等 | 字阶与字重层级纪律（标题/正文/辅助信息的尺寸对比） | 目录字体均为拉丁文，**不能假设支持中文**；本站不引入拉丁标题 webfont，中文标题继续走系统宋体栈（见第 5 节），避免无效下载与回退断裂 |
| Coolors | 工具页可读：调色板生成、对比度检查、真实设计预览、Token 导出 | 按角色定义 Token（背景/卡片/正文/次级/边框/强调/状态）+ 用对比度数值验收（本次所有文字色均实测比值，见第 11 节） | 不复制任何现成配色；本站暖米 + 深绿品牌色保持不变，只修不达标项 |
| Spline | 官网可读：浏览器内实时 3D、viewer 组件嵌入 | 3D 只适合极少量品牌辨识元素，且需有明确收益 | 未引入：实时 3D 运行时 + 外部场景依赖对静态参考站成本过高，收益不明确 |
| LottieFiles | 官网可读：dotLottie 比 GIF 小约 90%、Lottie JSON 小约 60%，强调轻量反馈动画 | 反馈动画只做"小而有目的"的：按钮按压、卡片悬停、收藏 toast（本站已有 toast，本次补齐 CSS 按压与悬停） | 未引入 Lottie/dotLottie 运行时；现有反馈用 CSS/SVG 已覆盖，无新增依赖 |
| Three.js Journey | 课程页可读：WebGL、粒子、滚动动画，另有性能优化章节 | 高成本效果先用图片/CSS/SVG 替代的判断标准 | 未引入 Three.js/WebGL；美食摄影本身就是视觉主体 |
| 3dicons | 官网可读：1500+ 开源 3D 图标、统一陶土渲染、在线编辑器 | 图标风格统一的原则（本站频道图标改走一致的圆角底 + 表情符号组合，不再各自为政） | 未下载任何 3D 图标：食物实景图片始终是主体，3D 图标不得替代美食摄影；外部素材许可证未逐项核对前不引入 |

**综合判断**：本站不需要"更炫的技术"，需要"更像杂志的首屏 + 更像工具的详情页"。3D、WebGL、Lottie 运行时、外部 3D 图标本轮全部不引入。

## 3. 现有 UI 的主要问题（均经截图或实测确认）

1. 顶栏换行断裂（桌面端实测）：品牌副标"食见"在顶栏挤压下断为"食/见"两行；"AI 助手"按钮断为两行。根因是顶栏溢出时品牌与按钮被 flex 压缩、内部文字换行。
2. 首页首屏无图片焦点：纯文字标题 + 搜索框，不像美食杂志；首屏没有任何食物摄影。
3. 四个内容分区布局完全同构：菜谱/烘焙/饮品/食材均为"筛选条 + 横滑卡片"，没有视觉节奏差异。
4. 次级文字对比度不达标：`--muted #8B8574` 在背景上 3.32、在卡片上 3.62，低于 WCAG AA 正文 4.5（实测，见第 11 节）。
5. 键盘焦点不可见：首页搜索框与搜索浮层输入框设了 `outline:none` 且无替代焦点样式；全站无 `:focus-visible` 规则。
6. 份量步进按钮仅 30px，低于舒适触控尺寸。
7. 无 `prefers-reduced-motion` 支持：`scroll-behavior:smooth` 与悬停过渡对减动效用户不友好。
8. 详情页长内容无页内导航：食材 → 步骤 → 技巧 → 问答需逐屏滚动，做菜时找步骤成本高。
9. 卡片标题无行数限制：长标题换行层数不一，网格行高不齐。
10. 顶栏在 1100px 视口溢出 34px（本次修复过程中由 5A 套件暴露，见第 10 节）：旧布局靠品牌副标与按钮换行"硬挤"才不出溢出，属于隐性债务。

## 4. 最终视觉方向

**高品质美食编辑杂志 + 实用烹饪参考工具**，两者权重相等：

- 杂志侧：首屏图片化、分区差异化、标题字阶拉开、留白与图片面积优先。
- 工具侧：详情页信息层级、份量控件、步骤可读性、搜索效率、触控尺寸、对比度、键盘可达性一律不为视觉让路。
- 不做的事：不对称布局不以牺牲可用性为代价；不缩小字体解决布局问题（沿用项目硬规则）；不改动任何配方数据与技术参数；不引入新依赖。

### 10.4 首轮失败的排查实录（不隐瞒）

首轮 5 套件跑完时 5D 失败 2/185、5C 失败 1/130、5A 失败 9/461（5F、5E 通过）。经逐项定位，均为本次改动引入，已全部修复并重跑通过：
